🚀 Deploy Gratuito na Vercel Configurado

O projeto já possui vercel.json e exportação do Express em server.ts prontos para a Vercel:

  1. Suba este repositório no GitHub e importe na Vercel.
  2. Nas Environment Variables do projeto na Vercel, defina:
    • ADMIN_USER = admin
    • ADMIN_PASS = atpromo123
    • GROQ_API_KEY = sua_chave_groq_gsk_...
  3. Os Mascotes customizados enviados nos Slots 1 e 2 e o seu login ficam salvos automaticamente no localStorage do seu navegador!
